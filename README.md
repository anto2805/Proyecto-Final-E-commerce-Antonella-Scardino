PROYECTO FINAL E-COMMERCE ANTONELLA SCARDINO
Nido & Co. 🌿

Sitio web e-commerce de diseño, decoración y calidez para el hogar, desarrollado con un enfoque minimalista y estética boutique.

## 🚀 Características del Proyecto
- **Diseño Responsive:** Adaptable a dispositivos móviles y de escritorio mediante CSS Flexbox y Grid.
- **Paleta de Colores:** Tonos crema y tierra (`#faf9f6`, `#b08d57`) para transmitir calidez y elegancia.
- **Carrusel de Categorías:** Secciones interactivas para Cocina, Habitación, Decoración, Perfumes y Accesorios.
- **Formulario de Contacto:** Integrado de manera funcional mediante Formspree.
- **Cero dependencias pesadas:** Desarrollado íntegramente con HTML5 y CSS3 estándar.

## 🛠️ Tecnologías Utilizadas
- HTML5
- CSS3
- Formspree (para gestión de consultas)
